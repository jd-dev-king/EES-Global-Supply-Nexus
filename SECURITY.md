# Security Policy

This repository is a portfolio simulation and must not contain production credentials, private supplier records, or regulated manufacturing data.

## Reporting a vulnerability

Please open a private security advisory through GitHub when available. Do not publish credentials, exploit details, or sensitive information in a public issue.

## Local configuration

Keep secrets in untracked environment files. The repository's `.gitignore` excludes `.env`, keys, certificates, runtime databases, and credential folders.
